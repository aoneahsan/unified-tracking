# Phase 02 — Audit Findings (prioritized)

**Audited:** 2026-05-26 · web/TS core (65 files) + iOS Swift + Android Kotlin · two parallel audit agents (security; functionality/quality/gap) + direct verification.

**Headline:** No CRITICAL/HIGH _security_ vulnerabilities — `yarn npm audit` clean, zero hardcoded secrets, no injection/RCE/XSS-via-user-data, fan-out error isolation is correct. The real issues are **(a) privacy controls that are declared but inert**, **(b) several dead/unwired subsystems** (EventQueue, most of the React API, `web.ts`), and **(c) one honesty gap: the native iOS/Android providers are stubs and not bridged**, despite being advertised.

Decision legend: **[FIX]** do it this release · **[DOC]** document honestly as a known limitation (out of scope to implement now) · **[DEFER]** note for a future major.
